## Implementation rule

Treat the packaging as the approved brand reference.

Do not: - change the mascot - change the product label - rewrite label
facts - invent nutrition values - invent ingredients - invent serving
instructions - alter regulatory markings

For web presentation, create a clean ecommerce visual system inspired by
the packaging, but do not make the website look like a flat copy of the
label.

## Asset handling

If original client assets are available, use them instead of recreating
them.

The supplied JPEGs are reference images. They are not necessarily the
final high-resolution ecommerce assets; Claude should retrieve the best
approved assets from the live Delsi source or client asset repository.
